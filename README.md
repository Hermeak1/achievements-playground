# git-playground

Git / GitHub 워크플로를 실제로 눌러보며 익히는 연습 저장소.

브랜치를 파고, PR을 올리고, 머지하고, 이슈를 여닫는 과정을 실제 저장소에서 직접 해보기 위한 공간입니다. 실무 저장소에서 잘못 눌러 배우는 것보다 여기서 망가뜨리는 편이 낫습니다.

## 다루는 것

- 브랜치 생성 → 커밋 → 푸시 → PR → 머지 → 브랜치 삭제까지의 한 사이클
- 머지 전략 3가지의 차이 (merge commit / squash / rebase)
- 이슈 생성과 종료, PR과 이슈 연결
- `gh` CLI로 위 과정을 터미널에서 처리하기

정리한 내용은 [NOTES.md](NOTES.md)에 있습니다.
